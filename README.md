# Hezarfen Flight Challenge

Toklutimur videosu "Fable 5.2 ile Hezarfen'i Simüle Ettirdim" için Claude Code + Fable 5.2 oturumunun bütün çıktıları: araştırma notları, kanat çizimleri, Blender modelleri, aerodinamik hesaplar, süzülme simülasyonu ve raporlar.

- Video: https://youtu.be/bo_RyUxBbrM
- Modele verilen komut: [`proımpt.md`](proımpt.md)
- Ayrıntılar ve yeniden üretme adımları: [`Hezarfen_Flight_Challenge/README.md`](Hezarfen_Flight_Challenge/README.md)

Hezarfen'in uçuşu bir rivayettir. Buradaki hesaplar ve simülasyon, modelin kurduğu basit bir modeldir; gerçek bir aerodinamik çözüm değildir.

Ham render kareleri boyut yüzünden repoda yok; birleştirilmiş videolar `Hezarfen_Flight_Challenge/renderlar/animasyon/` altında.
